How to make a QR code

        
    
          
  1. Type or paste a link or any text. For a Wi-Fi code, switch the first box to A Wi-Fi network and fill in the name, the password and the security type.
    2. 
          
  2. Leave error correction on Medium unless the code will be scuffed or small, then use Quartile or High.
    3. 
          
  3. Choose a module size. Bigger squares scan more easily from further away.
    4. 
          
  4. Save a PNG for a document or a screen, or an SVG to print at any size without blur.
    5. 
        


        
Making it scan reliably

        
    
          
  • Keep the blank border. The code needs four empty squares all round it, and this page adds them.
    • 
          
  • Keep it dark on light. Scanners read contrast, and many cannot read a light code on a dark background.
    • 
          
  • Print it at least 2 cm across, and larger if people will scan from a distance.
    • 
          
  • A shorter link makes a simpler code that scans faster. If the code looks very dense, shorten what is inside it or lower the error correction.
    • 
          
  • Scan one printed copy with a phone before you print a thousand.

Frequently asked questions

        

          
Does a QR code from this page expire?

          
No. The code holds your text itself, with no server in between, so it works for as long as it can be scanned. If it holds a link, the code keeps working, but the page it points to may move or disappear.

        

        

          
Which error-correction level should I choose?

          
Medium is a good default. The four levels let a code survive about 7%, 15%, 25% and 30% damage, and each step up makes the code larger and denser. Choose Low for a clean screen and short text, and Quartile or High for a code that will be printed on something that gets scratched or dirty.

        

        

          
How much can a QR code hold?

          
At the lowest error-correction level, up to 7,089 digits, 4,296 letters and digits (capitals only), or 2,953 bytes of any text. Higher levels hold less. A code that full is very dense and hard to scan, so a short link is almost always the better choice.

        

        

          
How do I make a Wi-Fi QR code?

          
Switch the first box to A Wi-Fi network, type the network name and password, and choose the security type. Phones offer to join the network when they scan it. Anyone who scans the code can read the password out of it, so treat the printed code like the password itself.

        

        

          
Can I change the colours?

          
Yes, but keep the code much darker than its background. The page warns you when the colours are too close, or when the code is lighter than the background, because many scanners cannot read an inverted code.

        

        

          
Does it work with Telugu, Hindi and other languages?

          
Yes. Text outside plain English is stored as UTF-8, and current phone cameras read it correctly. Some older scanner apps show garbled characters for it, so test with the phone your audience will use.

        

        

          
Is my text sent anywhere?

          
No. Everything happens in JavaScript inside your own browser. Nothing is uploaded and nothing is saved - close the tab and it is gone.
