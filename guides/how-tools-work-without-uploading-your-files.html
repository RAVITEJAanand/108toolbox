How our tools work without uploading your files

Most online tools ask you to upload your file to their server. The tools on this site never do: your own browser does all the work. This guide explains how that works, how the pages are locked down, and two simple ways to check it for yourself. Updated 25 November 2026.

Two ways an online tool can work

When you use a tool on a website, the work has to happen somewhere. There are two places it can happen:

  • On a server. Your file is uploaded to someone else’s computer, processed there, and the result is sent back. Your file has left your device, and what happens to it next depends on that service’s policies.
  • In your browser. The page brings the tool’s code to you, and your own device does the work. Your file is read from your disk into the browser’s memory and never travels anywhere.

Every tool on 108 ToolBox works the second way.

What happens when you pick a file

Take the Image Compressor. When you choose a photo, the browser reads it from your disk. The page’s own JavaScript draws it onto a hidden canvas, an area of memory the browser provides for pictures, and saves it again at a smaller size. The download button hands you that new file straight from memory. At no step is the photo sent over the internet.

The other tools follow the same pattern. Calculators do arithmetic in the page. The Merge PDF tool reads and writes PDF files with code that runs in the page. The Hash Generator uses the cryptography built into the browser itself. Close the tab and whatever you typed or chose is gone.

How the pages are locked down

Each page carries a set of rules for the browser, called a content security policy, that says where the page is allowed to send anything. On the pages without advertising the answer is nowhere: the browser itself refuses any attempt by the page to send data out.

Most tool pages are set up to carry one Google advertisement below the tool. On those pages the rules allow Google’s advertising servers and nothing else, and the tool’s own code still sends nothing. An advertising script runs inside the page, though, so the tools where people type passwords or keys, the Password Generator, the Hash Generator, the JWT Decoder and Protect PDF, carry no advertising at all. The privacy policy explains what the advertising does.

Check it yourself

You do not have to take this on trust. Two simple tests:

  1. Go offline. Open a tool and let the page finish loading. Then turn off Wi-Fi and mobile data and use the tool. It keeps working, because nothing it does needs the internet. (A few tools, such as PDF to Image, fetch their own code from this site the first time you use them, so try one file while you are still online.)
  2. Watch the network. On a computer, open the browser’s developer tools (F12 in most browsers) and choose the Network tab. Use the tool on a file. You will see no request that carries your file anywhere.

The honest limits

  • Your device does the work. A very large PDF or a batch of big photos can be slow on an older phone, because no powerful server is helping.
  • Nothing is saved for you. There is no account and no history. Download your result before you close the tab.
  • Tools can still be wrong. Working privately does not make a calculation right. Every tool page says so, and asks you to check results that matter.

Why this site works this way

People use these tools on payslips, bank statements, identity documents, contracts and family photos. None of those should have to leave your device to have a page counted or a picture resized. Keeping the work in your browser is the simplest way to make that promise, and to keep it.
