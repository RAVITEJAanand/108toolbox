PNG, JPG or WebP: which image format to use, and when

Picking the wrong image format gives you a blurry screenshot, a lost transparent background, or a photo too large to upload. This guide explains what each format really does, what converting can and cannot fix, and how to get a photo under an online form's size limit. Updated 25 November 2026.

The short answer

  • JPG for photographs.
  • PNG for screenshots, logos, text, diagrams, and anything that needs a transparent background.
  • WebP for pictures on your own website, where a smaller file means a faster page.

The rest of this guide explains why, so you can decide the cases that do not fit neatly.

Lossy and lossless

An image file is a grid of coloured dots, called pixels. A phone photo of 4,000 × 3,000 pixels is 12 million of them, and storing three bytes of colour for each would take about 36 MB. Every format shrinks that in one of two ways:

  • Lossless (PNG) packs the pixels more tightly and gives back exactly the same pixels when opened. Nothing is lost.
  • Lossy (JPG, and WebP in its usual mode) throws away detail the eye is unlikely to notice. The file becomes much smaller, and the lost detail never comes back.

Lossy works well on photos, where colours blend softly. It works badly on sharp edges such as text and lines, which is why a screenshot saved as JPG often shows faint smudges around the letters.

What converting can and cannot do

  • Converting a JPG to PNG does not restore quality. The detail the JPG threw away is gone. You get the same picture in a bigger file.
  • Converting a transparent PNG to JPG fills the transparent parts with a colour, because JPG cannot store transparency. Keep it as PNG or WebP if the background must stay see-through.
  • Saving a JPG again and again loses a little each time. Always work from the original file, not from an earlier copy.

Size depends on pixels first

The biggest thing that sets a file’s size is not the format but the number of pixels. Halve the width and the height and you keep only a quarter of the pixels. A picture shown 800 pixels wide on a web page gains nothing from being 4,000 pixels wide, so resize first and choose a format second.

Preparing a photo for an online form

Application forms for exams, jobs and government services often ask for a photo or a signature in a fixed format, a fixed pixel size and a file size inside a range, for example a JPG between 20 KB and 50 KB. A phone photo of several megabytes is far over that. The order that works:

  1. Read the form’s rules carefully: format, width and height in pixels, and the smallest and largest file size allowed.
  2. Crop the photo to the shape asked for with the Image Cropper.
  3. Resize it to the exact pixel size with the Image Resizer.
  4. Save it as JPG with the Image Converter, since most forms accept only JPG.
  5. If it is still above the limit, bring it down with the Image Compressor, and check the result is not so small that the face or signature turns blurry.

A photo resized to a few hundred pixels on each side usually fits a 50 KB limit easily as a JPG. Every form sets its own rules, so treat the form’s instructions as the final word.
